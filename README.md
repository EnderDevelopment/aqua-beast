# AquaBeast

AquaBeast is a Minecraft plugin that introduces a unique aquatic creature to the game. This plugin is designed to enhance the underwater environment with a new mob that players can encounter, interact with, or even tame. The creature is fully customizable and can be integrated into various gameplay mechanics, adding a new layer of depth to the Minecraft experience.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Once the server is running with the plugin installed, you can spawn the AquaBeast mob using in-game commands or by interacting with specific blocks or items.
2. The AquaBeast can be encountered in underwater biomes or spawned using custom commands.
3. Players can interact with the AquaBeast by feeding it, riding it, or engaging in combat.
